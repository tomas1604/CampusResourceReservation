# Milestone 3: API Testing Documentation

## Users Endpoints
### GET /api/users
Returns all users stored in the system.

### POST /api/users
Creates a new user in the system.


## Resources Endpoints
### GET /api/resources
Returns all available resources.

### POST /api/resources
Creates a new resource in the system.


## Reservations Endpoints
### GET /api/reservations
Returns all reservations currently stored in the database.

### POST /api/reservations
Creates a new reservation linking a user to a resource for a specific time period.
